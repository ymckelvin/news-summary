Firetiger joins Cursor
I'm excited to announce that the Firetiger team is joining Cursor.
Firetiger builds agents that work on software once it reaches production. They monitor rollouts, catch regressions, investigate incidents, and pass what they find back to coding agents.
The company was founded in 2024 by Rustam Lalkaka and Achille Roussel, who helped build and operate some of the largest production systems on the internet, at Cloudflare, Twitch, Segment, and Twilio.
They started Firetiger because they saw the potential for agents to remove operational toil and make production systems more reliable. Since then, coding agents have made it much easier to generate and ship code. But much of software engineering happens after the code is written, from getting changes safely into production to understanding and fixing what goes wrong once they're there.
Agents that write code should also be able to tell whether it works in production. Today, those systems are mostly separate. Cursor and Firetiger bring them closer together so an agent can ship a change, see how it behaves, and respond when something goes wrong.
You'll see Firetiger's work show up across Cursor as we build more of the path from writing code to running it in production. This is part of a broader investment in long-running, autonomous, context-aware agents for teams. That work also includes Cursor Origin, our Git forge built for the agentic era, and soon Change Monitors, which watch deployed changes and flag problems as they appear.
We're looking forward to building this with Rustam, Achille, and the rest of the Firetiger team.
